Entry for the make.fun bounty [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

## The entry

```
Router Died. Marriage Followed.
```

31 characters. One Wi-Fi network name, one whole story.

## The story behind it

The router died. The Wi-Fi went down. And somehow — nobody can quite
explain how — the marriage went down with it. Two sentences, one
domestic disaster: a dead router, a household at war over the blinking
box in the corner, and a relationship that apparently depended on the
signal staying up. Every passer-by who sees this name in their network
list knows exactly what happened in that house.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes the name to
`/output/entry.txt`, after checking the gate: UTF-8 text, 1–32
characters, not only whitespace. No network, no secrets, no files read
outside this repository.
